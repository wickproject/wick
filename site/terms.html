Pseudo Anonymous, Inc. ("we", "us", "our") operates the Wick software at getwick.dev.

Service Description

Wick is an MCP (Model Context Protocol) server that provides browser-grade web access for AI coding agents. It runs locally on your machine and returns clean markdown content from web pages.

Wick is open-source software distributed under the MIT License. All features — Chrome-grade TLS fingerprinting, embedded Chromium (CEF) rendering, content extraction, search, and per-fetch telemetry — are free.

Privacy

Wick runs locally on your machine. We do not see, store, or transmit the content of pages you fetch.

Wick reports anonymized per-fetch telemetry to releases.getwick.dev — hostname, strategy, ok/fail, status, timing. No URL paths, no page content, no IP addresses persisted as a data point. Opt out with WICK_TELEMETRY=0 or touch ~/.wick/no-telemetry. Full details on the telemetry docs page.
